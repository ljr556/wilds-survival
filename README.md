# 荒野求生 · 第一人称 3D 生存游戏

**在线试玩：<https://ljr556.github.io/wilds-survival/>**（手机请横屏）

你在一片无名森林中醒来。砍树、采石、挖矿、打猎、生火、盖房，活过一个又一个夜晚——入夜后森林里会有东西游荡。

浏览器直接打开即可，无需安装、无后端、无账号；进度保存在本地浏览器里。

## 玩法系统

### 生存

- 生命、饱食、水分、体力四条状态，外加**体温**：下雨、雷暴、夜晚会降温，靠**篝火**取暖（8 米内生效），体温过低会持续掉血
- 饥饿或脱水归零会持续掉血；吃饱喝足会缓慢回血；深水区会窒息
- 受伤、中毒（生肉/蘑菇有概率）、力竭都会影响行动

### 采集与工具迭代

| 层级 | 斧（砍树） | 镐（采石/挖矿） | 武器 |
|---|---|---|---|
| 石制 | 石斧 2.2× | 石镐 2.2× | 木矛（16 伤害） |
| 铁制 | 铁斧 3.6× | 铁镐 3.6× | 铁矛（26） |
| 钢制 | 钢斧 5.2× | — | 钢剑（38） |

拿错工具也能挖，但效率只有 15%–25%；铁/煤矿必须用镐。工具层级越高，掉落越多（每级 +25%）。

资源节点包括：树木（木/树枝）、岩石（石/燧石）、**铁矿**、**煤矿**、浆果丛（浆果/纤维）、草丛（纤维）。采空的节点会在几分钟后重新长出来。

### 合成与工作台（23 个配方，三档加工台）

- **徒手**：木棍、绳索、火把、石斧、石镐、木矛、绷带、篝火、工作台、木墙
- **工作台**：铁斧/铁镐/铁矛、钢斧、钢剑、兽皮衣、铁甲、水囊、棚屋
- **篝火**：冶炼铁锭、钢锭、烤肉、烧开水

加工链是完整闭环：**矿石 + 煤 → 铁锭 → 钢锭 → 钢制武器**；**兽皮 → 兽皮衣/铁甲**（提供减伤与保暖）。

### 建造

篝火（照明 + 取暖 + 烹饪）、工作台（解锁进阶配方）、木墙（阻挡怪物）、棚屋（夜晚睡觉跳到天亮并恢复）。

### 昼夜、天气与夜晚怪物

- 一天约 10 分钟：白天 06:00–19:30，夜晚 19:30–05:30（时间显示在顶部）
- 天气系统：晴 / 多云 / 下雨 / 浓雾 / 雷暴，每 1.5–3 分钟随机切换，会改变天空色、雾浓度、光照强度与气温；雷暴有闪电
- **夜晚刷怪**：白天的森林只有野兔、鹿和野猪；入夜后刷出**夜狼**与**林魈**（血量 46 / 110、伤害 9 / 18），数量随天数增加（最多 12 只），天亮后自动散去

### 生态

- 被动动物会游荡、觅食、被靠近时逃跑；野猪被打会反击
- 夜狼会捕食鹿和兔子（不是只盯着玩家）
- 动物会随昼夜与距离动态刷新与回收，保持生态密度

## 技术与美术

- **引擎**：Three.js（本地内置 `vendor/three.module.js`，无 CDN 依赖）
- **地形**：程序化高度图（整数哈希 + 分形噪声 + 湖盆），150×150 网格
- **地表**：`onBeforeCompile` 注入 splat 着色器，按高度与坡度混合草地/泥土/岩石/沙地四张贴图
- **实例化**：树木、岩石、矿脉、浆果丛、草丛共 900+ 个对象用 InstancedMesh 渲染，可见的只有个位数 draw call
- **美术**：全部由 Meowa `game-assets` skill 生成——4 张 64×64 无缝地表材质（草地/泥土/岩石/沙地）+ 45 枚 24×24 物品图标（资源、工具、建筑三批）
- **适配**：桌面指针锁定 + 手机触屏（摇杆/拖动视角），像素比与植被密度按设备分档，帧率过低会**自动降质**（降像素比 → 隐藏草叶）
- **存档**：localStorage（世界种子、时间、玩家状态、背包、已建建筑、已采节点与重生倒计时），每 20 秒与关闭页面前自动保存

## 已验证（Chromium 实测）

- 世界生成：928 个资源节点（300 树 / 180 岩 / 46 铁矿 / 32 煤矿 / 110 浆果丛 / 260 草丛），地形 −3.7 ~ 23 米
- 采集：石斧砍树得「木材 ×3、木棍 ×1」；石镐采石得「石头 ×3、燧石 ×1」、采铁矿得「铁矿石 ×3」
- 合成：木材+石头 → 篝火与工作台
- 建造：篝火与工作台放置成功，靠近篝火合成台自动切换为「篝火」
- 战斗：钢剑击杀夜狼掉
- 生存：熟肉 +38 饱食、净水 +45 水分
- 天气：切到雷暴后雨粒子生效
- 手机横屏（844×390 触屏模拟）：摇杆推进 3.4 米、视角拖动、合成面板可开、无报错
- 控制台零报错、零 404

## 已知限制

- 高精度建模不是这条技术路线的强项：生物与建筑是程序化低模，靠形状与配色辨识
- 无多人联机；存档在各自浏览器里
- 软件渲染（无 GPU）下帧率会明显下降，游戏会自动降质
